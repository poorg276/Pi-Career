# PiCareer 0.1.14：企业岗位检索与官网入口

城市、企业、岗位至少填一项。仅填写企业会检索各类岗位，填写城市或岗位后以原文证据逐项核验；主列表最多10条，数量不足时显示实际数量。手动录入、编辑、删除、收藏和JD转入继续支持离线准备。

## 实现与使用

官方招聘入口先于岗位展示，可立即打开；同一企业最多展示4个入口，优先随包已核验目录，缓存记录核验日期和归属依据。此次增加万兴科技官网与其官网直接指向的校招/实习系统。公开北森/Zhiye接口限于已核验的企业租户，不将任意平台域名视作企业官网；目前覆盖万兴科技、科大讯飞的已登记租户，其他平台按HTML/JSON-LD、搜索正文和官网兜底处理。

默认无需Tavily或模型配置即可读取已支持的官方结构化职位；模型可辅助其他网页的证据提取，不能补写无依据字段。每次最多6组查询、24个待核验职位、并发3项、90秒；少于10条时继续尝试其他引擎，在时限内保留已取得的有效结果。同一岗位跨网站镜像优先保留官方证据。名称没有明确Agent方向时，只使用职责中的Agent开发证据，优先条件里的相关经验不算职责。

网络仍按Windows系统代理选择路径。Electron ClientRequest单次捕获重定向，每一跳重新校验公开网址、DNS和代理，禁止跳转本机/内网。网站验证/登录、代理连接、HTTP拒绝、限流、超时、动态页面与解析失败分别说明。页面脚本不在后台执行，职位列表POST限定于已核验租户的固定公开查询接口。

点击准备面试/匹配知识点时重新读取对应职位的职责和要求。北森原文链接采用官网实际使用的公开GUID，不误用内部数字JobAdId；不能核验时由用户补充JD。返回恢复条件、结果、备选、收藏和滚动位置。

## 验收

- 最终类型检查通过；全套139项自动化通过。后续入口数量限制通过相关23项复测。
- 实际Electron的125%/150%岗位界面通过：最小字号13px、长模型名、严格/备选、双向JD返回、收藏与设置返回、取消重试、迟到请求隔离、旧收藏保护。
- 实际Electron代理夹具验证公开302跳转、内网跳转阻止、验证码跳转阻止、HTTP403/429、连接断开和代理故障不绕过。
- 手动岗位在125%下验证无模型/断网新增、编辑、失败保留输入、重启恢复、可选来源、删除；150%打包版也已通过。
- OAuth夹具验证真实Pi授权阶段、Windows长凭据加密及重启恢复、代理令牌交换/刷新/SSE、取消重试、HTTP/令牌/保存失败。
- 真实联网、无Tavily：万兴科技单条件10条；长沙+万兴科技+Agent开发3条。读取实际职责和要求，打开真实原文，完成两条JD跳转。已有真实账号连接测试及Agent web_fetch/Context回归通过，均在隔离配置副本运行。

详细证据：`docs/evidence/desktop-jobs-0.1.14.json`、`docs/evidence/recruitment-live-0.1.14-dev.json`、`docs/evidence/recruitment-live-0.1.14-packaged.json`、`docs/evidence/package-0.1.14.json`、`docs/evidence/installed-0.1.14.json`、`docs/evidence/installed-startup-0.1.14.json`与`docs/evidence/installed-model-0.1.14.json`。前期失败测试记录没有被标为通过；上述记录是修复后的复测结果。

## 发布状态与限制

安装包、便携包已生成并完成打包版真实联网、模型连接、150%界面与手动录入复测；便携包CRC和关键运行文件校验通过。覆盖安装成功，安装前后数据库SHA256一致，桌面快捷方式保留。安装后原OAuth及模型恢复、真实连接、聊天/刷题/收藏/学习记录核验通过。源码包由scripts/package-source.py生成并检查CRC，三个交付包的SHA256见release/SHA256SUMS-0.1.14.txt。不保证所有招聘平台可读取，也不保证每组条件均有10条岗位。网站接口、验证策略和职位状态可能变化，招聘有效性以原站为准。

保留用户授权、学习记录、聊天、刷题、收藏、桌面快捷方式；不改动pi-main或YxAgent。
