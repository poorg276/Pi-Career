# PiCareer 0.1.9：Hot100 官方题意与刷题记录

日期：2026-10-11。环境：Windows 10 x64、Electron 44.7.0。已完成实现、构建、打包应用验收及本机覆盖安装。

## 使用方法

Hot100 直接显示题目目录与工作区。题面只显示官方中文题意描述，保留必要列表、行内代码、上下标和图示；示例、约束、进阶、提示、讲解及参考实现入口不再显示。

在 Monaco 中编写 Python3，代码自动保存。点击「力扣原题」先保存代码，再复制到系统剪贴板并打开对应题目。在官网粘贴、运行、提交，然后回到编辑器下方选择「正确／错误」、填写可选心得并保存。每道题单独计数，从第 1 次开始；已保存记录可修改正误和心得，次数保持不变。目录绿点代表正确，红点代表错误，按次数从左到右排列；多次记录可横向滚动。

保存或复制失败时会明确提示，可重试；未保存的代码与记录输入不会因切换模块而丢失。最新手动记录决定正确题数和错题筛选。旧代码草稿保留，旧本地判题结果单独标注、不推断次数或官网通过情况。

## 官方内容核验

- 全部 100 题的官方编号、slug、中文名称及 Python3 模板逐题核对。82 题从公开页面数据获取，18 题通过正常浏览器访问后读取页面自身数据；访问验证页未作为题面使用。
- `content/official-source.json` 保存官方中文源快照、模板、来源与获取时间；`content/official-problems.json` 保存经过描述段落截取及受限 HTML 解析的展示快照。获取日期均为 2026-10-11。
- 截取在第一处示例／约束／进阶标题之前结束，兼容第 51 题的嵌套容器。描述中的三张必要图片为第 17、118、160 题，全部随包提供并有 SHA-256 校验；其他示例图片不展示。
- 上下标保留在第 56、207、394、295 题。HTML 标签和属性采用白名单，脚本、事件属性、表单及嵌入内容被移除，链接由系统浏览器打开。
- 每次构建执行 `scripts/verify-official.ts`，核验 100 题身份、原始内容摘要、模板、显示内容和本地图片；校验失败阻止构建。快照可以离线再生成及核验。
- 力扣题面与模板保留原权利归属，不因 PiCareer 的 MIT 许可证而改变。来源：[官方热题 100](https://leetcode.cn/studyplan/top-100-liked/)。显示内容以此次官方快照为准，不承诺后续官网更新自动同步。
