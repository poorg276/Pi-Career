# PiCareer 0.1.13：项目与科研经历优化

## 使用

点击侧栏或工作台「简历优化」后只显示标题、模型入口与两张模式卡片。选择「项目经历优化」进入独立编辑页；「完整简历」暂显示「该功能还在开发中......」，不创建草稿。返回模型设置前先保存输入，从设置中的「← 返回简历优化」恢复原页；再次点击侧栏回到模式入口。

经历编辑页按顺序填写：

1. 目标岗位职责与要求，可留空进行通用优化。
2. 现有项目/科研经历概述，必填。说明材料对应关系、本人工作与团队工作的区别、技术方法及已知成果。科研请注明作者身份和论文／专利状态；时间未知或指标未测量可以直接说明，不需补造。
3. 导入项目、论文／专利材料并选择发送片段。支持 PDF、DOCX、TXT、Markdown、PNG/JPG、源码目录和 ZIP；扫描页需要当前模型支持图片。不执行材料中的代码或指令。导入只操作应用材料副本，不修改原文件。
4. 查看供应商、模型及发送范围，点击「依据提供的信息生成简历中的项目经历及科研经历」。一个可停止任务完成材料检查、撰写和独立核验。
5. 核对并编辑生成结果，可按项或整体复制。证据和修改说明默认折叠，不进入复制文本；原文及已编辑内容可在版本恢复入口找回。

关键个人贡献、材料对应关系、科研身份或成果状态缺失，或概述与资料存在未解决冲突时，在概述旁显示具体补充提示，保留旧文稿；补充后重新点击生成。纯文字模式不强制上传附件。每项成稿限2～4条精炼描述；无依据的类别、未知时间和未测量效果省略。

编辑页顶部是紧凑草稿选择及新建、保存、删除操作。输入自动保存，保存失败会提示重试。旧经历的项目、科研文字和已回答补充信息合并为统一概述；原字段、材料与版本仍保留。旧完整简历草稿保留在后台。本版无独立分析、逐项问答、模板、预览或导出入口。

## 数据与事实边界

简历记录仍位于原 SQLite，材料仍位于应用专属 resume-materials/<草稿ID>。生成只使用本轮概述及勾选的项目／科研材料，不使用旧未回答问题阻断，也不发送旧模板或照片。任务事件沿用草稿ID、请求ID与版本检查，不能由迟到结果覆盖手动编辑；运行中编辑被禁用。

引用必须对应真实片段，文本引用逐字核对，材料摘要里的数字必须有引用依据；标题及条目数字、成果状态和贡献再次检查。图片依据是模型对可见内容的识别，不能等同于独立证明。用户概述是本人声明，自动核验不能替代用户最终核对，尤其是作者身份、团队分工和成果状态。

生成中的结构或措辞问题允许一次有界修订，并再次独立核验；不自动重试网络请求。关键个人事实不足仍要求补充概述，不通过修订补造事实。岗位要求仅是优化目标，不能当作用户已完成的工作。停止、解析失败、模型失败及最终核验失败保留输入、材料与上次文稿。删除草稿只删除其专属副本与记录，原文件和以前导出的文件不受影响。模型分析不联网查找个人资料；点击生成后，将明确列出的输入与材料发送给所选供应商。

## 验收

本版验收执行记录保存在 evidence/resume-experience-0.1.13-*.json；实际界面截图位于 screenshots/resume-0.1.13-*。测试采用不含私人信息的合成项目和未发表科研材料，模拟服务与真实模型分别记录，不把模拟响应当作真实模型结果。

回归范围包含概述迁移、旧完整草稿保留、必填与关键缺失阻断、冲突、引用和虚构指标拦截、核验失败保留文稿、取消与重复操作、复制编辑内容、版本恢复、切页、设置返回、重启恢复和原文件保护。桌面检查覆盖125%／150%缩放及小窗口；其他模块工具、面试、学习、每日资讯和既有授权另行回归。

类型检查及124项自动化测试通过，其中21项为简历回归。真实 Electron 的125%／150%流程通过，覆盖生成中离开模块、返回后停止。使用已连接的 gpt-6-luna 对合成材料完成纯文字无JD、源码与文字/扫描PDF混合、未投稿论文及贡献/身份不足四类真实模型验收；逐条对照概述与材料，确认没有虚构指标或将设计写成已实现，论文明确保留草稿阶段。真实成稿与证据见 evidence/resume-experience-0.1.13-real.json。

最终发行版也完成同样四类真实模型验收，见 evidence/resume-experience-0.1.13-real-packaged.json。打包版125%／150%交互、七模块最小窗口与150%布局、每日资讯规则、实际Pi SDK配合模拟模型的36次协议请求均通过。便携ZIP逐项CRC及八项运行文件摘要与已测解包版一致，未包含用户数据库。

测试过程中曾遇到网络、引用定位和模型条目数量问题，失败均保留原稿。当前只允许一次结构整理和一次针对写作问题的修订，仍不能保证所有模型请求都成功；最终不通过会提示重试，不发布未经核验的新文稿。合成材料验收通过不代表任意真实论文或项目都已核实，用户仍需确认最终个人事实。
