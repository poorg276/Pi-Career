# PiCareer 0.1.1 外观调整

对应用户的四项截图反馈；沿用首页、侧栏和四模块的页面布局。

| 反馈 | 实现 | 验收方式 |
|---|---|---|
| 缩小窗口后左侧底部消失，无法滚动 | 品牌区和设置/个人空间区固定，中间导航占用剩余高度并独立滚动；滚动内容与品牌区保留间距 | 在最小 1024×700 窗口用鼠标滚轮滚动侧栏，确认底部始终完整可见，主内容不跟随滚动 |
| Windows 顶部黑色标题栏突兀 | 暖白标题栏 `#f7f8f5`、黑色窗口按钮，保留原生最小化/最大化/关闭与拖动区域 | 系统主题设为深色后验证原生按钮可见，并捕获整个原生窗口截图核对颜色 |
| 右侧滚动条粗且明显 | 页面、侧栏、嵌套面板和编辑器采用 6px 滚动条；滑块黑色 22% 不透明度，悬停 38%，轨道透明 | 检查真实溢出区域宽度、颜色、滚轮行为及截图 |
| 字体偏绿，阅读不自然 | 中文优先使用微软雅黑 UI；主文字 `#202020`，辅助文字使用中性灰色，标题字重统一；装饰图标与代码语法保留各自颜色 | 七个页面扫描可见 UI 文字，排除代码语法、图标和错误状态后无带色文字，并查看截图 |

## 验证

- `npm run check`：通过。
- `npm run test:desktop`：首页导航、编辑器载入参考解、Python 本地通过、背诵批次推进通过，无页面运行错误。
- `scripts/visual-check.mjs`：可对开发版或 `PICAREER_EXE` 指定的打包版执行。七个页面在最小窗口下没有内容横向溢出，侧栏底部完整可见，切换页面会复位主内容滚动位置。
- 最终打包版的 125% / 150% 缩放检查均通过；持久记录分别见 [125% 检查结果](evidence/appearance-0.1.1-125.json) 和 [150% 检查结果](evidence/appearance-0.1.1-150.json)。七个页面均无运行错误。
- [完整原生窗口截图](screenshots/appearance-0.1.1.png) 包含真实 Windows 窗口按钮；[小窗口侧栏滚动截图](screenshots/sidebar-0.1.1.png) 显示中间导航独立滚动后底部仍完整可见。完整截图集位于 `.test-data/appearance-*`。
- 现有桌面安装已升级到 0.1.1，安装程序退出码为 0；已安装的主程序与 UI 包哈希均匹配本次发布文件，桌面快捷方式目标正确。安装版在隔离测试数据目录重复通过七个页面的 125% 外观检查，见 [安装记录](evidence/installed-0.1.1.json) 和 [安装版检查结果](evidence/appearance-installed-0.1.1-125.json)。

标题栏采用 [Electron 官方 Window Controls Overlay 方案](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)，原生按钮由 Electron 管理，应用提供配色和拖动区域。

本次更新只调整窗口与 UI，不变更数据库结构、模型配置、聊天记录、刷题草稿或学习进度。
