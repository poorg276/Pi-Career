## 内容状态

100 题按力扣热题 100 组织，本项目独立编写概述与实现，未复制完整平台题面。题单日期和版本为 2026-10-10。每题已通过参考实现测试，但本地用例规模不等于力扣完整测试集；复杂度约束不能仅靠小规模输出比较证明。

知识库含 210 条初始条目，已完成唯一性、字段、标签、出处链接结构检查，并逐条初审简明答案。抽查了 Python asyncio、LangGraph 持久化、MCP、Transformer、RAG 评测等原始资料。部分来源是主题扩展阅读，尚未完成全部 210 条答案与精确来源段落的一一核对，因此不把它们宣称为 210 条已全面核验的正式题库。企业面经始终作为公开网友参考，不标为官方题库。

## 尚未通过的最终验收项

1. 用户实际 API 供应商连接、付费额度和工具调用兼容性。当前测试使用自建协议替身，不能代替真实服务。
2. 用户真实订阅登录、授权码成功交换、令牌过期刷新及不同供应商的可用模型；仅授权入口和取消流程已验证。
3. 真实 Tavily 搜索、JD 正文读取，以及依赖它们的企业岗位/企业资料面试；没有提供 Tavily Key，未伪造联网结果。
4. 独立未装开发工具的干净 Windows 虚拟机、Windows 11、多显示器，以及真正跨版本数据库迁移。缩减 PATH 只验证当前机器上不依赖这些命令。
5. 知识条目的逐条出处一致性复核、所有算法的更大规模/随机与性能测试、企业面经按年份的人工整理。
6. Windows 代码签名证书尚未配置；安装包属于未签名个人测试发行版。

完成上述检查后才能将本版标记为全面通过发布验收。首次使用请先在「模型与设置」配置模型和 Tavily，再运行一场真实面试与岗位搜索。
