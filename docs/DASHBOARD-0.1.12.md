# PiCareer 0.1.12：界面细节与每日资讯

窗口标题统一为 **PiCareer·辅助求职Agent**。简历优化在侧栏与工作台使用同一文档加笔图标，知识背诵仍使用书本。工作台卡片按模拟面试、企业岗位检索、LeetCode Hot100、八股知识背诵、简历优化排列，编号01～05。

## 每日资讯规则

- 按电脑本地日期，每天首次启动自动尝试一次；同日重启、切页和唤醒不会重复联网检索。
- 持续打开跨日后，返回工作台、重新激活工作台窗口或其恢复可见时检查；没有午夜后台定时任务。
- 保留手动刷新，不限制次数；手动更新也满足当日自动更新条件。
- 每次请求开始前将日期写入SQLite。失败、超时或关闭中断仍计入当天尝试；保留缓存和真实提示，可手动重试。
- 新接口 `ensureDashboardUpdated` 仅检查并启动到期请求，现有 `refreshDashboard` 用于手动刷新。运行中的检查与刷新合并为同一请求；跨日运行不会提前消耗次日尝试。
- 旧缓存没有日期标记时，从有效的 `attemptedAt` 转换本地日期；无有效记录则更新。中断的加载状态恢复为失败提示。知识点和学习进度仍沿用原规则。
