# PiCareer 0.1.4 通用 Agent 改造与验收

日期：2026-10-10。模型授权沿用 0.1.3；本次改造集中在通用 Agent、共享搜索的取消参数以及新增服务的系统代理通道。

## 已实现

- 历史对话移入最左侧导航；点击「通用 Agent」展开/折叠，右键重命名，标题同步到会话和首页。1～80 字，空名称不能保存。
- 用户靠右、助手靠左，去掉重复角色标签。16px 正文与输入框、14px 代码；Markdown 列表、加粗、表格、代码块和浏览器链接；消息中的 HTML 不执行。
- 对话占据主区域，输入框固定在底部；阅读旧消息不被流式输出拉回。处理中文输入法的 Enter 候选确认。
- 使用实际 Pi SDK Agent 循环；无目录即可读取日期、天气、搜索和网页。选择目录后启用 read/ls/find/grep/write/edit/powershell，保留写入与命令审批。
- 项目说明文件、项目 `.pi/skills` / `.agents/skills`、应用级 Skills 可加载并支持 `/skill:名称`；不加载第三方可执行扩展。
- 会话 ID、轮次 ID、工具 ID 和 revision 隔离状态；用户输入立即保存，文字阶段进度最多每 150ms 保存。导航不丢流，重命名不会被旧输出覆盖；异常恢复标记中断，不自动重放操作。
- Open-Meteo 中文城市名补全处理：长沙优先查询「长沙市」，避免服务只返回同名乡镇；保留真正重名的候选确认。
