# PiCareer 0.1.10：工作台资讯与招聘入口

日期：2026-10-11。环境：Windows 10 x64、Electron 44.7、Node 24.18；当前电脑系统代理。

## 使用

工作台的宣传区已替换为企业招聘官网、Agent 技术进展和今日知识点，下方标题改为“PiCareer工作台”。原四个功能入口、最近对话、学习进度、顶部模型栏及侧栏保留。

- **招聘官网**：16 个离线可见入口，涵盖腾讯、阿里巴巴、华为、字节跳动、拼多多、美团、百度、京东、网易、小米、快手、小红书、哔哩哔哩、携程、科大讯飞、深信服。点击使用系统浏览器打开。仅表示官网入口，不代表具体岗位有效性。
- **技术进展**：每次启动后台更新一次；切换页面或唤醒已有窗口不会重复触发。点击“刷新”可重新检索。优先近30天，不足时补充近90天且标明；无法核实三条时显示实际数量，不补造内容。先显示缓存，更新失败保留缓存及原更新时间，详情见“更新说明”。
- **今日知识点**：来自已预置的 LLM、RAG、Agent、框架、评测和部署知识库。同一天重启保持所选条目，“换一条”立即切换，次日更换。不会增加背诵计划完成数。

辅助文字至少13px，正文14px。宽窗口资讯与知识点分两栏，小窗口改为单栏。

## 资讯依据与边界

官方列表和正文均经后台系统代理获取。新闻来源限定于 OpenAI、Anthropic、LangChain 官方发布及确认的框架官方仓库；新闻不是普通搜索摘要的直接包装。每条保存发布日期、日期依据、正文摘录、来源网址和检索时间。正文不执行，也不能调用本机工具。

单次最多6组搜索、12篇正文，并发最多3，总时限90秒；搜索和读取各有单独超时。公告、招聘、培训、投资、营销、教程、无发布日期及90天外内容排除，同一网址或同名事件去重。现有公开网页请求的 DNS、重定向、内网地址、响应大小及代理校验沿用。

默认提供中文技术标题及标为“原文摘录”的有据摘要，无模型配置也可获取。已有模型授权时，可用一次限时请求辅助中文翻译，保留技术专名；校验记录 ID、原文引文和新增数字，失败保留原文摘要。新闻查询和官方公开摘录会发送给实际网站/搜索引擎；启用翻译时摘录发送给已选择的模型，不发送用户聊天或学习内容。

真实联网核实了 Deep Agents 技能机制更新、Managed Deep Agents 的任务调度与配置更新、LangGraph CLI 版本功能更新等三个不同事件。各条具体来源与日期见随附 JSON 证据。本机部分官方站点可能拒绝自动读取，如 OpenAI 在部分请求中返回 HTTP 403；失败被记录，使用其余可核实来源，未绕过验证或系统代理。文章来源随每次启动变化，不将验收样例硬编码进应用。

招聘入口经过官方域名或企业官网交叉核验，并通过本机 Electron 请求得到 HTTP 200。字节招聘根地址返回404，改用有效的 `/experienced` 入口；阿里采用其集团官网明确链接的招聘入口。部分官网依赖 JavaScript，HTTP与官方归属核验不等于已完成各站的登录、投递或岗位查询。
