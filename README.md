# PiCareer

基于同级 `pi-main` 本地 SDK 的 Windows 个人 Agent 与求职工作台。版本 0.1.14，单用户、本地存储。

项目已从0.1.13交付版本建立本地Git基线，后续功能与修复通过提交保存，每次发布使用附注版本标签。发布目录保留最近两个已验收版本，较早交付包保存在 `archive/releases`；详见 [Git与发布维护](docs/MAINTENANCE.md)。

## 启动

- 安装版：运行 `release/PiCareer-0.1.14-x64.exe`，安装后使用桌面 PiCareer 快捷方式。
- 便携版：解压 `release/PiCareer-0.1.14-x64.zip`，双击其中的 `PiCareer.exe`。不要在压缩包中直接运行。
- 当前源码目录也可双击 `启动 PiCareer.cmd`，打开 `release/win-unpacked/PiCareer.exe`。

安装版与便携版均自带 Electron 与 Pi SDK，无需安装 Node/Python。Hot100 代码在力扣官网运行提交。面向 Windows 10/11 x64；发行包尚未购买代码签名证书。

## 首次配置

1. 打开「模型与设置」，选择自定义 API 或 Pi 支持的供应商。
2. 自定义接口填服务地址、准确的模型 ID、接口类型和 API Key，点击「测试连接」。默认地址只是占位，未附带账户或额度。支持 OpenAI Completions、Responses、Anthropic Messages 兼容接口。
3. 使用订阅时，点击对应供应商的「连接」，授权弹窗立即出现，并自动打开系统默认浏览器。保持 PiCareer 开启，在浏览器完成账号选择和授权；弹窗保留重新打开、复制链接和取消操作。OpenAI Codex 可切换设备码登录，也可展开备用区域粘贴本次完整回调地址。显示「已授权」后选择该供应商的模型、保存并测试连接。失败或取消后应重新连接，旧链接不再可用。过期凭据由 Pi 刷新，刷新失败时重新连接。
4. 联网搜索和公开网页读取无需额外密钥。可选填写 Tavily API Key；配置后优先调用 Tavily，失败时使用 Bing、DuckDuckGo 公开搜索。验证或登录受限页面会如实提示。

密钥、OAuth 令牌通过 Electron safeStorage 调用 Windows 系统加密后存入 SQLite；不会把明文凭据写入前端存储。不要将密钥填进聊天。聊天和学习内容本身是本地明文，提交的内容会发送给所选模型服务；搜索词会发送给实际使用的搜索引擎，网页地址会发送给目标网站或已配置的 Tavily。

## 使用

### 简历优化

点击「简历优化」先进入模式入口。选择「项目经历优化」，填写选填 JD 和必填的「现有项目/科研经历概述」，可导入项目源码、论文或专利，勾选实际发送片段，再点击「依据提供的信息生成简历中的项目经历及科研经历」。分析、信息检查、撰写和核验合为一个可停止任务。关键贡献、材料对应关系、科研身份或成果状态缺失时，在概述旁提示补充；未知时间、未测量指标可省略。生成结果采用每项2～4条简洁描述，可编辑、按项复制或整体复制，证据在独立折叠区。

材料支持 PDF、DOCX、TXT/Markdown、PNG/JPG、源码目录及 ZIP；扫描页和图片需要图片模型。生成前显示发送范围与供应商，不执行材料中的代码。编辑页内保留紧凑草稿选择、新建、保存、删除和生成版本恢复。旧经历合并到概述，旧完整简历草稿保留在后台。本轮「完整简历」仅显示「该功能还在开发中......」，不提供模板与导出入口。详见 [0.1.13 使用说明与验收](docs/RESUME-0.1.13.md)。
### 通用 Agent

点击左侧「通用 Agent」进入聊天，再次点击可折叠或展开对话列表；右键对话名可「重命名」或「删除」。删除入口会先停止当前对话的任务，再展示清理清单；确认后删除聊天及 Pi 会话记录，并将能够确认由本对话新建的文件移入回收站。原有项目文件、外部修改或其他对话引用的文件会跳过，未登记产物不从历史文本推测。用户消息靠右，助手消息靠左，支持 Markdown。对话内容自动保存在本机，生成中可切换页面，返回后继续查看；向上阅读不会被新消息拉回底部。

不选择目录也可查询系统日期、城市天气、网页搜索与公开正文。天气使用 Open-Meteo（当前天气为模型数据，显示地点、数据时间和来源）。联网请求遵循 Windows 系统 HTTP/HTTPS 代理，代理失败不会静默改为直连。运行时以最多三行浅色动态文字显示工具进度，结束后收成一行状态；最终回答保留来源链接，原始工具记录仍保存在本机。

标题区仅保留单行对话名称。输入框左下角显示当前模型，点击进入设置；其右侧是工作目录入口。整轮回答结束后显示 Context 估算余量；它是 Pi SDK 结合模型目录估算的上下文占用，不是账户额度。自定义 API 的真实窗口未确认，或自动压缩后暂无可靠用量时，显示「暂不可用」。旧记录不反推用量；停止和失败有不同结束提示。

通过 PowerShell 或 Skills 脚本生成文件时，Agent 可用 `outputPaths` 声明预期文件；只有执行前不存在且执行后核验通过的普通文件会登记为清理产物。未声明的命令产物不会自动随对话删除。

支持流式对话、停止生成和本地历史恢复。选择工作目录后，Pi 可以读取文件、查找、写入、编辑和执行 PowerShell。写入前显示原内容与拟写入内容，命令执行前显示命令；可以拒绝或在本次打开 App 期间授权指定目录的命令。

对话空闲时可选择或更换目录。加载项目根目录的 AGENTS.md / CLAUDE.md（AGENTS.override.md 优先）和 `.pi/skills`、`.agents/skills`，以及 `%APPDATA%/PiCareer/agent/skills`。在相应目录放置包含 SKILL.md 的技能文件夹后，下轮对话自动发现；输入 `/skill:名称` 可显式调用。技能脚本不会跳过命令审批。

文件路径限制在所选目录；应用级 Skills 目录仅开放读取。经批准的 PowerShell 以当前用户权限执行，属于真实本机命令，不是操作系统沙箱。求职流程不开放本机工具。

### 企业岗位

城市、企业、岗位任填一项或组合搜索。主列表最多10条，优先读取官方公开职位数据，按条件、正文证据、官方来源与可确认日期排序；官网入口先于岗位展示。北森/Zhiye适配目前限于目录中已核验企业的公开接口，其他动态平台受限时保留官网入口。主列表仅列出有正文证据支持全部已填条件的岗位；真实招聘但条件不全、不一致或仅有摘要的结果放在折叠的「相关备选」，逐项显示差异。Agent 岗位需有名称或明确职责证据，仅出现 AI 不会自动匹配。百科、旅游等无关页面不会作为岗位；招聘入口单独展示，不计入岗位数量。没有严格结果不表示企业没有招聘。

点击「查看匹配证据」可核对企业、城市和岗位的原文引用。每次最多 6 组查询、24 个待核验职位，最多并发 3 项，总时限 90 秒；可停止，取消或超时后保留已核验结果。可选 Tavily 优先，没有合格结果继续尝试 Bing、DuckDuckGo；各来源的失败原因单独提示。

「准备面试」「匹配知识点」会重新核验并提取对应职位的 JD；无法核验时先展示原因和可编辑输入，确认后才进入新建表单。点击「← 返回岗位检索」恢复条件、结果、相关备选、收藏视图和滚动位置，不重新搜索；应用运行期间切换其他页面同样保留。旧收藏不会删除，未核验的条目转入前重新检查。招聘有效性始终以原站为准。

点击企业岗位标题旁或收藏中的「＋ 手动录入目标岗位」填写企业、地点、名称、职责及要求。岗位类型支持实习、校招、社招、未注明；学历、经验、毕业年份、薪资、来源链接和备注选填。没有招聘网址、没有模型配置或断网时均可保存；职责和要求保留换行。关闭新增弹窗后，本次打开 App 期间会保留未保存的草稿。

保存后进入我的收藏，手动记录标为「用户手动录入」，可查看完整详情、编辑或删除。删除前确认，不删除已生成的面试和学习计划。「准备面试」「匹配知识点」直接使用后台已保存的信息组成 JD，无需联网读取或模型提取；正式生成练习仍需要已配置模型。选填招聘链接可通过「原文」打开。

### 模拟面试

填写企业、岗位、JD（文本或公开网页链接）。检索公开资料后生成 8 道模拟主问题，每题最多追问 2 次。退出后从历次面试恢复；也可提前结束生成报告。来源不足时显示基于 JD 模拟，问题不冒充企业真题。评分是模型反馈，不是企业录用判断。

### Hot100

提供全部 100 题官方中文题意及 Python3 模板的离线快照，获取于 2026-10-11，仅展示题意描述段落及其中必要图示，不展示示例、约束、进阶、提示或答案。原始来源、获取时间和 SHA256 随源码保留，详见 [Hot100 验收记录](docs/CODING-0.1.9.md)。

Monaco 自动保存代码，已有草稿不被新模板覆盖。点击「力扣原题」先保存并复制当前代码，再打开对应题目；在官网粘贴、运行和提交。复制或保存失败时明确提示，可重试。Hot100 页面不加载 Python runner，安装包不包含旧 WebAssembly 运行时。

编辑器下方按每题独立记录第几次刷题。根据官网结果选择「正确／错误」，可填写心得，再保存本次记录。历史记录可编辑正误及心得，编号保持不变；目录中的绿点表示正确，红点表示错误，从左到右对应次数。最新记录决定正确题数与错题筛选。旧版本地判题结果单独保留，不计次数，也不代表官网通过。

### 八股背诵

预置 210 条原创知识条目，包含稳定编号、问题、答案、解释、标签、难度、出处和版本。输入 JD 后进行标签与文本匹配，再由模型筛选；模型不可用时明确使用本地匹配结果。可补充企业名称，联网资料会参与选题并保存来源快照，不作为官方题库。

先显示去重后的实际总数，锁定条目版本，每批 10 条。输入「这10条背完了」或点击按钮推进，重复操作不会多计数。每完成 50 条进入最多 10 题的小测，剩余不足 50 条的结尾补结业测验。测验不设及格门槛，低分或未评分条目进入复习清单。进度与未完成测验可在关闭后恢复。

## 数据与恢复

默认目录为 `%APPDATA%\PiCareer`。`picareer.sqlite` 保存设置、学习记录、岗位收藏、面试和代码草稿；`sessions/` 保存 Pi 会话。启动时生成数据库 `.backup`。升级和正常卸载保留数据。

备份时先关闭 App，复制整个 userData 目录。恢复时关闭 App 后用备份替换同目录；若仅恢复数据库，将 `picareer.sqlite.backup` 复制为 `picareer.sqlite`，先保留当前数据库。Windows 加密凭据通常只能由原 Windows 用户解密，换电脑/用户后应重新配置凭据。不要只复制 EXE 作为数据备份。

## 从源码构建

目录保持 `pi-main/`、`PiCareer/` 同级；`YxAgent/` 不参与本项目构建。

开发需要 Node 24、npm 11 和 Windows PowerShell；Python 仅用于生成/验证题库和图标，不是应用运行依赖。

```powershell
cd E:\Agent_learn\pi_Agent\PiCareer
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1
# 如果 Electron 官方下载不可用，可显式使用镜像：
# powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1 -UseMirror
npm run dev
```

脚本安装依赖时禁用生命周期脚本，仅显式执行 Electron 的运行时下载脚本。下载源码的 SDK 包版本标记为 0.87.1，但模型目录要求 schema 6，官方同版本 npm 模型数据为 schema 3，因此仅采用官方 `@earendil-works/pi-ai@0.99.0` 的生成模型目录并经过本地校验；SDK 仍是本地源码构建。源码摘要及逐文件 SHA-256 记录在 `resources/pi-source.json`。本地上游源码保持不变。0.1.3 在随包 SDK 副本应用受摘要校验的兼容补丁，记录在 `resources/pi/node_modules/@earendil-works/pi-ai/dist/picareer-compat.json`；源文件改变或补丁无法精确匹配时停止构建。

已准备好的工作区可直接：

```powershell
node scripts/prepare-sdk.mjs
npm run check
npm test
python scripts/verify_problems.py
node scripts/verify-pyodide.mjs
node scripts/integration.mjs
node scripts/runner-test.mjs
npm run package
```

`integration.mjs` 使用真实 Pi SDK 和本地模拟模型端点；不是付费模型验收。`smoke.mjs` 验证桌面主流程，`visual-check.mjs` 检查七个页面的小屏布局。测试数据只写 `.test-data`，不会写正常用户目录。

`node scripts/codex-desktop-check.mjs` 验证真实 Electron、系统代理解析、本地 HTTPS 模拟授权、Windows 长令牌加密、SSE 和过期令牌刷新。`PICAREER_SCALE` 可设为 `1.25` 或 `1.5`，`PICAREER_EXE` 可指定安装或便携版。测试 CA 仅在测试进程信任，不安装到系统证书库。

`node scripts/chat-check.mjs` 验证通用 Agent、Skills、代理天气与搜索、重命名、中文输入法及异常恢复。`node scripts/live-chat-check.mjs --real-account` 会先备份数据库，再使用当前真实账号执行一次日期/天气请求；只在需要真实验收时运行。

`node scripts/live-web-check.mjs --real-account` 先备份数据，再使用当前真实账号、无 Tavily 密钥执行中文/英文搜索及公开正文读取，仅新增或继续标注的验收对话。可加 `--quick` 做一次搜索与正文复验。`node scripts/installed-check.mjs` 只读检查现有安装版本、授权恢复和历史 Context，不发送模型请求。

更多信息见 [验收记录](docs/ACCEPTANCE.md)、[架构说明](docs/ARCHITECTURE.md)。

源码发布：完成安装验收后运行 `python scripts/package-source.py`，生成不含用户数据库、依赖或临时测试目录的源码 ZIP，并更新三个发布文件的 SHA256 校验清单。
